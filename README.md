# PowerWatch

A responsive nationwide power-outage alert prototype built with Next.js.

## Run locally

Requirements: Node.js 18.18 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

## Included

- Confirmed, likely, active, and recovered outage states
- Alert filtering and details
- Saved locations
- Push, SMS, and email preference controls
- Lead-time and severity preferences
- Browser-local persistence
- Responsive desktop and mobile layouts

> The prototype uses mock data. It is not a certified emergency warning system and should not replace official utility or emergency alerts.
