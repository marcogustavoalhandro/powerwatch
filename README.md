# PowerWatch

A responsive nationwide power-outage alert app prototype.

## Features

- Regional planned-outage and likely-risk feed
- Confirmed, likely, active, and recovered status labels
- Saved locations and location filtering
- Alert detail views
- Notification preferences
- Mock data with clear timestamps and sources

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

> This prototype uses mock data. It is not a certified emergency warning system.
